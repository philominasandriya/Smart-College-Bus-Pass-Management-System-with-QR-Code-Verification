# Smart College Bus Pass Management System with QR Code Verification 

## Abstract
In modern educational institutions, efficient transportation management is crucial for ensuring smooth daily commutes for students, faculty members, and staff. Traditional college bus pass systems rely heavily on manual registration, physical receipt collection, paper passes, and visual verification by drivers.These conventional methods often lead to severe operational inefficiencies, including long waiting queues, vulnerability to pass forgery or duplication, lack of real-time passenger tracking, and delayed communication regarding fee payments or emergency schedules. To address these limitations, the Smart College Bus Pass Management System with QR Code Verification is proposed as a centralized, role-based web application designed to digitize, secure, and streamline the entire college bus pass lifecycle.
The primary objective of this project is to provide a comprehensive digital platform that connects users, drivers, and administrators within a unified ecosystem. The system architecture is organized into distinct role-based portals: the User Portal, Driver Portal, and Administrator Dashboard. The User Portal allows students and faculty members to view their profile and digital bus pass, make secure bus fee payments, check assigned bus and driver details, submit urgent pass requests for single-day travel, receive emergency pass alerts, provide feedback based on admin-configured questions, and file formal complaints. The Driver Portal equips bus drivers with active route rosters, registered passenger details (including department, course, and boarding points), payment status indicators, a camera-based QR code scanner module for instant passenger verification, and access to administrative complaints and warnings.
The Administrator Dashboard serves as the master control center, providing comprehensive management capabilities across the entire transportation network. Administrators can review and approve pending registrations for students, faculty, and drivers, manage student and driver profile directories, configure bus routes and dynamic fare tables, monitor paid and unpaid user accounts, publish payment cycles, approve urgent pass requests, generate emergency passes, publish and edit feedback questionnaires, review user complaints, and issue official warnings to drivers. The system is developed using PHP for server-side processing, MySQL for robust relational database management, HTML5, CSS3, and  JavaScript for responsive user interfaces, and specialized QR code libraries for generating unique cryptographic pass IDs and performing rapid client-side verification.
The development process follows the Scrum framework, an Agile methodology that promotes iterative development, continuous feedback, and modular implementation across structured sprints. This approach ensures systematic requirements analysis, database design, interface development, QR scanning integration, and rigorous testing for functional correctness and security. By automating registration, fee tracking, and optical verification, the system eliminates duplicate registrations, prevents unauthorized pass usage, reduces administrative workload, and ensures transparent communication across the institution. Ultimately, the project bridges the gap between conventional administrative practices and modern web technologies, delivering a reliable, scalable, and user-friendly transportation solution.
Keywords: Bus Pass Management, QR Code Verification, Role-Based Access, Web Application, PHP, MySQL, Agile Methodology.
## Tech Stack
- **Backend:** PHP
- **Database:** MySQL (WAMP)
- **Frontend:** HTML5, CSS3, JavaScript
- **Libraries/Tools:** PHPMailer, QR Code Generation & Verification Modules

## Key Features
- **Role-Based Portals:** Dedicated dashboards for Administrators, Drivers, and Students/Users.
- **QR Code Verification:** Instant optical scanning module for drivers to verify valid bus passes.
- **Fee & Pass Management:** Digital multi-installment fee tracking, urgent pass requests, and profile directory management.
